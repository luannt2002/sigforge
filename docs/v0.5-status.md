## Known limitations found so far
- The `sync` junk test compares only the first line of an error, so a multi-line error such as `errors.Join` is not pinned. The code
  is correct; the test gap is open.
- `matcher.Match` compiles the DB's patterns on every call: about 0.3 s per call on a 7695-tech DB.
- Tags inside `<textarea>` and `<title>` are still parsed by the `dom` matcher. Suspected, not measured.
