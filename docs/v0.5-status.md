## Reviewed after merging
These three changes were merged on 2026-11-11 without an independent review (owner's decision): the review was cut
off by a usage limit and only the judge's checks ran. Each has now been reviewed on its own. In all three the review
found the code correct, and found mistakes the tests would not catch.

**Conditions** — `requires` / `requiresCategory` / `excludes` gating, label inheritance and a carrier index.
- At merge: truth table 77/77 rows; real 7695-tech DB: 5.57 ms on a page resolving 6093 techs (the previous round
  took 1.66 s); mutation sweep: 2 survivors, both equivalent.
- After review: two truth-table rows were added, and a test that holds the carrier index to a plain pairwise
  reference on generated DBs and pages, small and large.

**Passive `dom` rules** — match only start tags the page really has.
- At merge: golden true positives 42/42; golden false positives 190 → 8; mutation sweep: 11 survivors, all equivalent.
- After review: eleven cases were added to the `dom` rule tests, on how comments, selectors and attribute operators
  are read.

**One meaning of "answered"** — `watch` reports REMOVED, UNCHECKED and GONE per identity.
- At merge: a model test checks 500 generated multi-identity runs.
- After review: two mistakes that would mix one identity's outcome into another's (a lead kept UNCHECKED instead of
  GONE, or another identity's reason printed) would not fail any test. The code is unchanged; this is recorded as a
  known test gap.

Gate on the tree with all of the above: `go test ./...` passes 1163 tests and subtests, 0 fail, in 25 packages; none of
the 1032 names that passed at `39619bc` is lost.
