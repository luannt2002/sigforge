## Merged WITHOUT an independent review (owner's decision, 2026-11-11)
The review of these three changes was cut off by a usage limit; only the judge's checks ran.

- Truth table: 77/77 rows.

- Mutation sweep: 2 survivors, both equivalent.

**Passive `dom` rules** — match only start tags the page really has.
- Golden true positives 42/42; golden false positives 190 → 8.
- Mutation sweep: 11 survivors, all equivalent.

**One meaning of "answered"** — `watch` reports REMOVED, UNCHECKED and GONE per identity.
- A model test checks 500 generated multi-identity runs.

Gate after the merge: `go test ./...` 1032 pass, 0 fail, no test name lost; `-race` clean on all 25 packages.

## Known limitations
- The `sync` junk test compares only the first line of an error, so a multi-line error is not pinned. The code is correct.
- `matcher.Match` compiles the DB's patterns on every call: about 0.3 s per call on a 7695-tech DB.
- Tags inside `<textarea>` and `<title>` are still parsed by the `dom` matcher. Suspected, not measured.
