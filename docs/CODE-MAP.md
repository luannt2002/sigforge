# Code map

One line per package: path → what it owns → the API a consumer calls (if any).
`framework/` is pure infrastructure and never imports `modules/`; `modules/intel/`
is the domain. Per-feature specs live beside this file (`docs/<package>.md`).

## framework/ — infrastructure (knows nothing about fingerprints)

| path | owns | consumer API |
|---|---|---|
| `framework/fsio` | file read + crash-safe atomic write | `Read`, `WriteAtomic` |
| `framework/fetch` | bounded, honest HTTP GET (no hardcoded URL; size + status + timeout guards) and the ONE choke point every outbound request goes through: a host that answered 429 gets nothing more until its `Retry-After` passes (`ErrRateLimited`); per-host sent/held-off counts; opt-in disk cache that revalidates with ETag / Last-Modified (304 ⇒ stored body); `GetMeta` + `MaxAge` serve a synced catalog with no request and say so (`Meta.Cached`, `FetchedAt`) so callers label it a snapshot; when a catalog source fails, `GetMeta` serves the stored copy flagged `Meta.Stale` + `Meta.Err` (stale-if-error) and callers label it `stale`; `Download` is the same for a body too large for memory (a whole-ecosystem dump): streamed to the store, bounded by the caller's context rather than the client timeout | `New`, `(*Client).Get`, `(*Client).GetMeta`, `(*Client).Download`, `(*Client).Do`, `(*Client).Stats`, `Meta`, `HostStats`, `ErrRateLimited`, `Client.CacheDir`, `Client.MaxAge` |
| `framework/define` | shared constant (`ServiceName`) | `ServiceName` — currently unused anywhere (see audit note) |

## Honesty invariant (spans the domain)

Absence is never "safe": `cve.StateUnknown` (not checked) ≠ `cve.StateNoKnownCVE`
(checked, nothing listed — still not a guarantee); likewise `lifecycle.StateUnknown`
≠ `StateSupported`. A detected version is a spoofable LEAD, not proof. CPE/CVSS/EOL
values are taken verbatim from the operator's feed, never fabricated.

The v0.4 `unified` contract carries this invariant across every source at once: its
seven `State` values keep `not_checked` / `source_unavailable` / `unknown_product` /
`unknown_version` apart from `not_affected_by_advisory`, and only
`potentially_affected` / `affected_by_advisory` (`State.Applicable()`) are actionable
leads — none of them "proof". See `docs/unified-contract.md`.
